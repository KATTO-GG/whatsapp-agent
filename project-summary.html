🔄

Session Persistence

Each WhatsApp user maps to a persistent Claude conversation via UUID session IDs. Context survives restarts.

🖼️

Image Understanding

Images downloaded via Media API, converted to base64 data URLs, embedded in prompt as markdown for Claude vision.

📁

File Transfer

Upload any file (code, logs, ZIPs) with MIME detection, size limits (5MB/16MB/100MB), path allowlisting.

⚡

Proactive Messaging

Agent can initiate: task complete/failed/blocked notifications, approval requests, input prompts with ref tracking.

🛡️

Security First

Token in .env (gitignored), no secret logging, path allowlisting, size validation, deduplication via wamid.

📦

ZIP & Send

zipAndSend() archives directories with archiver.js, uploads as document, cleans up temp ZIP automatically.

💻

Claude CLI Integration

Uses ~/.local/bin/claude with --resume for continuity, --print --output-format json for parsing, bypassPermissions for automation.

🔁

Rate Limit Handling

429 responses trigger automatic retry with retry-after header. Poll replaced (409) handled with immediate retry.

🧹

Clean Architecture

ES Modules, dotenv config, single agent.js (~630 lines), no framework bloat. Runs on Windows/Pi/Linux.

// Core loop - agent.js async function mainLoop() { while (true) { const { messages } = await pollUpdates(); for (const msg of messages) { await markRead(msg.id, true); const reply = await processMessage(msg); if (reply) await sendMessage(msg.from, reply); } await new Promise(r => setTimeout(r, 1000)); } }
